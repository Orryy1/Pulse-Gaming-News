Cheap measuring tools from the November 2026 world-class audit. All read only; none spends API credit.
Run them with Python and Pillow; plan_stats.mts needs @electric-sql/pglite and a COPY of data/db, never the live one.

sheet.py       contact sheet with timestamps: sheet.py <video> <out.jpg> <every_s> [start] [end] [cols] [cellw]
measure.py     dark share, longest hold, repeat share, distinct pictures: measure.py out.jsonl 2 <episode dir>...
pace.py        cuts a minute and brightness: pace.py name=path ...
plan_stats.mts share of plate (blank panel), clip and still per episode, words, "you" rate, hook length
scr.py         prints title, hook, beats, take and loop from an /admin/export dump

Numbers to watch: plate share under 10% and none in the first 5 s, clip share above 50%, words a minute 175 or more on Shorts, brightness (meanY) above 80.
