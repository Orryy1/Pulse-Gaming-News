## Thesis

A game can pause while preparing a graphics pipeline, then run the same moment
smoothly from cache. This is one possible cause of a one-time hitch, not a
universal diagnosis for every stutter.

## Audience and outcome

PC players should leave able to recognise the first-run/second-run pattern,
understand what a pipeline state object bundles and know why the correct caveat
matters.
